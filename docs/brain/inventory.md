# Inventory

Generated by node scripts/inventory.mjs — do not edit

## Families
- `ai-cap` · a server path calls the model and must refuse once the business has used its monthly cap.
- `ai-draft` · an AI flow must store what the model suggested next to what the person saved, with a closeness score.
- `ai-learning` · code copies something into a `'__master__'` pool or lists a business's AI material for the platform admin.
- `business-delete` · a business is deleted and everything it owns on the server must go.
- `chip` · a small rounded label, toggle, tab or filter. Do not add a page-local chip: pick a variant. The old `c-toggle-chip`, `c-tap-chip`, `c-tab-pill`, `c-filter-chip` classes no longer exist.
- `client-picker` · any screen that links a record to a client (new-inquiry dialog, event stage bar, the client section).
- `cloudinary-requests` · building a signed upload, expiring download link or delete request.
- `cost-badge` · a cost is shown that may be missing prices.
- `edit-gate` · a page offers save/edit on a business item.
- `empty-state` · an empty list or a search with no results.
- `engine-classes` · a style used by more than one component (buttons, inputs, modals, chips, empty state).
- `entity-data-service` · a new entity type needs a client data service.
- `entity-form` · a form edits a named entity, or must warn before leaving with unsaved changes.
- `entity-schemas` · a new stored collection needs a shape.
- `event-plan` · anything that computes quantities, costs or prices for an event.
- `feedback` · any wait, success or error the user must see.
- `file-store` · a server path stores, reads, links or deletes a private uploaded file.
- `form-field` · any form input with a label.
- `helpers` · any pure helper (time, number, text). Never page-local.
- `http` · any call to the server API; never a raw `fetch` or a hand-built `/api/v1` URL.
- `kitchen-state` · state that several pages read or change (the loaded entity collections); never a page-local copy.
- `list-logic` · a list needs search, sort, filters or "clear all".
- `list-page` · any screen that lists entities.
- `modal-controller` · code needs to open a popup and await the result.
- `modal-shell` · any popup. Render the shell inside the owner's `@if (isOpen)`; never draw `.c-modal-overlay` by hand.
- `model-media` · a model call carries audio or a PDF.
- `module-gate` · a link, chip, screen, button or request belongs to a module. The server is the gate; the browser only hides.
- `modules-registry` · the server gate or the browser service asks whether a business has a module. One shared file, so both use the same rule.
- `multi-pick` · the value is a list (allergens, labels, categories) and the user adds/removes chips.
- `number-box` · a box whose only content is an editable number. Not for rows that mix free text and numbers.
- `page-entry-loading` · a route needs its collection loaded first.
- `search-combobox` · the user types to find an item (or a new one) and picks it — recipe/product/ingredient search, dish and category pickers, equipment search. Server searches pass `[clientFilter]="false"`; rich rows use an `<ng-template>` child.
- `server-auth` · a server route checks who is calling, scopes data to a business, checks a write permission or limits a rate.
- `stepper` · any +/− button that changes a number. The page keeps its own skin (cook-view ink set, menu paper pill).
- `supplier-picker` · a line may be bought from one of several priced suppliers and the owner chooses.
- `taxonomy` · a page reads or adds a category, unit, label or kind.
