# תנאי הפיילוט של FoodVibe

**טיוטה לעורך דין — לא לחתימה**

1. **פיילוט חינם.** ההשתתפות בפיילוט ללא תשלום. משך הפיילוט נקבע בנפרד לכל עסק, ונרשם בהסכמה בין הצדדים.
2. **הנתונים של העסק.** המידע על הלקוחות של העסק (שמות, טלפונים, פניות והזמנות) שייך לבעל העסק. FoodVibe מעבדת אותו אך ורק כדי להפעיל את השירות עבורו.
3. **סטטיסטיקה מצטברת.** FoodVibe רשאית להשתמש בנתונים מצטברים ואנונימיים בלבד, ללא שמות וללא מספרי טלפון, כדי לשפר את השירות.
4. **סיום בכל עת.** כל צד רשאי להפסיק את ההשתתפות בפיילוט בכל עת, בהודעה מראש.
5. **יציאה וייצוא.** בסיום הפיילוט יקבל בעל העסק ייצוא CSV של הלקוחות, הפניות וההזמנות שלו. לפי בקשתו, הנתונים יימחקו.
6. **פרטיות ומחיקה.** לקוח של העסק שמבקש שיימחק המידע עליו יימחק לפי בקשה. נתונים ישנים של פניות והזמנות נמחקים אוטומטית לאחר 24 חודשים. פניות בנושא פרטיות: יש להוסיף כאן כתובת דוא"ל ליצירת קשר.
