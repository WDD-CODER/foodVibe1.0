## Decisions
- Spec globs use `**/*.spec.ts` · the plan globs `recipe-builder/**` and `ai-recipe-modal/**` also match .html/.scss and Karma aborts with a load error (same as runs 421, 438).
- Added `src/testing/test-lucide-icons.ts` to the plan scope · the test icon set mirrors `app.config.ts`; without `ClipboardPaste` there every spec that renders the new paste button or tab throws.
- An unlinked row (name, no product) is valid with an empty or 0 amount, but a negative amount still fails · reopening a saved recipe shows `amount: 0`, which must not block the next save.
- `recipeFormValidator` (at least one ingredient) left unchanged · a recipe made only of unreadable lines still needs one row with an amount; out of the plan's scope and the plan's checks all start from an existing recipe.
- Pasted unit words resolve through `UNIT_ALIASES`, then `TranslationService.resolveUnit` (also tried with the gershayim form of a quote), then a unit key typed as-is (e.g. `cup`) · so `ק"ג`, `ק״ג`, `גרם`, `כוס`, `kg` all work; anything else stays part of the name with unit `unit`.
- A line whose number is followed only by a unit ("2 ק"ג") becomes a text row · nothing is left to name the ingredient.
- Leading bullets (`-`, `•`, `*`) are stripped before parsing, but a text row keeps the original line as pasted · so "never dropped" still shows exactly what was pasted.
- Linked pasted rows take the product/recipe's stored name for `nameHebrew`/`nameSnapshot` · matches the search-pick path.
- "הדבק מצרכים" is hidden when the ingredients array is disabled (history view disables the whole form) · the table has no read-only input and the page file is frozen.
- Paste tab reuses the text tab's textarea (8 rows, same styling) · no new scss in the modal.
- No `saveShot` for pasted recipes (INV-6, plan note) · applied to approve, reject, generate-again and close.
- Unknown-unit AI rows keep amount, unit `unit`, name `<name> (<unit>)`, no link · exactly the plan; `applyPatch` (AI edit) keeps its old behaviour (only the shared matcher was swapped in).
