## Decisions
- Touch detection = `window.matchMedia('(pointer: coarse)')` read once at construction (signal `coarse_`) · simple and testable by spying `matchMedia`.
- One native `type="date"` input serves both modes (hidden 1px picker on desktop, full-cover overlay on touch via modifier class) · avoids a second element.
- On touch the native input takes `id` and `aria-label`; the text input becomes `readonly`, loses `inputmode`, `id`, tab stop, and is `aria-hidden`.
- Native input is bound `[value]="value()"`; `onPicked` now also accepts an empty value (phone "clear") and commits `''`.
- `[attr.id]` used instead of `[id]` so a null id does not render as the string "null".
- Narrow scope exception: `src/app/shared/breadcrumbs.md` row for `date-field/` reworded (no more "calendar button"); `public/assets/data/dictionary.json` `open_calendar` removed (allowed by the plan).
