## Decisions
- Built the sibling `src/app/shared/search-combobox/` (S1b), not extra flags on `custom-select` · the copies need a page-owned query, min characters, a result cap, grouped/rich rows, a textarea, a "no results" line, Tab hand-off, an inline layout and a controlled open state: far over 3 flags (ADR 0025).
- `search-combobox` reuses `KeyedPickerSearch`, `filterOptionsByLabel`, `addOptionLabel`, `findOptionByLabel`, `app-add-option-row`, `app-scrollable-dropdown`, `app-input-clear` and the engine classes `.c-input-wrapper` / `.c-picker-search-row` · no new `.c-*`, no copy of the helpers.
- Look: `variant="box"` is the engine input box; `variant="plain"` is styled by the page through `--search-combobox-*` CSS variables on the host · pages keep their paper/glass look without `::ng-deep`; two unlayered `::ng-deep .c-dropdown` rules live in the component (engine `.c-dropdown` is unlayered, so a layered rule would lose).
- Option template is found by the template variable `#optionTemplate`, not by `TemplateRef` type · a type query also matches the template of an `@if` block.
- Removed the menu page's document-level capture keydown handler · it only forwarded arrows/Enter to the three pickers that now handle their own keys.
- Menu page: dish query text still lives in `MenuPickerSearchService.dish`; its `section` and `eventType` members were deleted (service + spec added to scope) · they only held state the combobox now owns.
- Section picker: choosing "add" closes the search first (the old keyboard path did; the old click path left it open) · one behaviour for both.
- Section-category rule X now compares the on-screen label only (old code also matched the English key) · the shared rule 3; typing the raw English key now offers `הוסף "<key>"`.
- Recipe-book ingredient list now opens directly under the search field, not under the chips below it · the shared box anchors to its own field; the filter panel looks otherwise the same.
- Logistics list keeps spanning the whole add row (`--search-combobox-position: static`), but uses the shared glass list instead of the old solid white one · fewer page-local styles; z-index 50 kept.
- Add row text colour is the primary colour everywhere (preparation search used the success colour) · one look.
- Arrow Up/Down reopens a closed list when something is typed (all pickers, not only logistics); Tab now closes the list in every picker (dish row and recipe-book filter used to keep it open) · rule K.
- Preparation search: Enter with the list closed (after Escape) no longer picks the top match; it only blocks a line break · rule K says Enter picks while the list is open.
- S9: `chip-search-dropdown` is NOT migrated and is marked `@deprecated` (ADR 0025, registry) · the product form relies on the inline chip box, `showAddNewAlways`, `noOptionsLabel`, `searchFilterFn` and add/remove outputs, which `custom-multi-select` lacks; migrating would change behaviour. Critical Question 1 stays open for the Human (adding those behaviours to `custom-multi-select` is the recommended follow-up plan).
- Scope additions (small, required): `docs/agent/standards-domain.md`, `docs/agent/standards-reuse.md`, `scripts/lib/registry-families.mjs` (lint hint now names `app-search-combobox`), ADR 0025, `_paper-ui.scss`, `menu-picker-search.service.ts` + spec, this run file.
- Dictionary: no new keys; existing `add_new_*`, `search`, `no_*` keys reused.
