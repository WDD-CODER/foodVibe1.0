## Decisions
- `useListControls` takes the page's own signals and needs no injection context (no `inject()` inside) · simpler, and testable without TestBed.
- `setSort` on a page without sort signals is a no-op; supplier and venue pass `useListControls<never>({ search })` · they have no sort today, behaviour unchanged.
- `clearAll(...resetters)` only runs the page's own setters · each page keeps its own filter signals, as the plan says.
- Search widening (Critical Question 1) accepted: all six filters use `matchesSearch` (`normalizeHebrew` on both sides). Menu library's haystack (name, type, date, tags) is now matched field by field, not as one joined string · a query can no longer match across the seam between two fields.
- `list-shell` `cards` is an `@if/@else` around the `.table-area` section; the table branch keeps the same elements and classes · table DOM unchanged. The cards branch reuses `.table-area` / `.table-body` with a `--cards` modifier so arrows, phone height and scroll indicators keep working.
- S9 venue: environment chips and the select-all pill moved into the shell filter panel (`shell-filters`), "clear filters" into `shell-filter-clear`; the count pill now comes from the shell (`list_result_count`) and the page-local `resultCountText_` is removed · the shell has no slot for an inline filter bar. Small visible change (filters in the side panel, scrolling card area, filter toggle button); covered by human cards 1-3.
- S10 menu library skipped · its chrome is a centred single-column list (max 56rem) with a select-based filter bar and a sort control; the shell would turn it into a multi-column grid with a side panel, a large visible change the plan forbids (Execution Notes). Its handlers still use the shared controls (S7).
- S11 trash skipped · grouped sections with their own header actions, no search/filter/selection; the shell's fixed-height card area, filter toggle and empty panel would be new chrome (Critical Question 2: skip).
- S12 metadata manager skipped · no list, only manager cards and a jump nav; nothing for the shell to own (Critical Question 2: skip).
- Dictionary and `styles.scss`: no changes.
