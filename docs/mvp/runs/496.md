## Decisions
- `addItem` reuses the first blank row (skipping the row being renamed) and only resets the search query when it creates a new row, so text already typed in the open row is not wiped by a second «הוסף מנה» click. Plan said keep `setQuery` on the index; this is a small deviation for that reason.
- `dishKey` removed, `getDishMetaKey` used at its call sites (identical bodies); the explanatory comment lives in the util JSDoc to keep the page net-zero.
- Print hiding via `[class.no-print]` on the host; no CSS change, no scope exception.
