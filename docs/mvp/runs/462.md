## Decisions
1. **D4 built as recommended** · price and unit gaps look like supplier / category gaps: one mark, one tooltip, price listed first; only the colour changes with severity (red when name or unit is missing, amber otherwise).
2. **Critical question 2 (low stock)** · the «מלאי נמוך» badge stays its own small badge (plan recommendation).
3. **Critical question 3 (phone)** · the mark is a button; tap opens the box, tap outside or Escape closes it (same pattern as the «חלקי» badge).
4. **Critical question 4 (unnamed-unit and unpriced)** · one red circle whose box also lists «מחיר» (priority: invalid, then unpriced chip, then triangle).
5. **`missing_unit` icon `ruler` -> `scale`** · `ruler` is not registered in `app.config.ts` or the test icon pick, so a row with no unit would have thrown "icon not provided" when its tooltip rendered (the old tooltip had the same hidden defect). `scale` is registered; `app.config.ts` is outside the scope block, so the icon changed in `VALIDATION_FIELD_ICONS` instead.
6. **Tooltip stays inside the click-guard** · the wrapper `.validation-badge` is added to the `onRowClick` early-return list, so a tap on the box (not only on the button) never opens the edit page. A tap on the name still does.
7. **`closeStatus(id)` only closes when that product's box is the open one** · otherwise the document click that reaches the previous row's click-outside directive would undo a tap on another row's mark.
8. **Enter/Space on the mark stop at the button** · the row has `(keydown.enter)` / `(keydown.space)` that open the edit page; without `stopPropagation` the keyboard could not open the box.
9. **Tooltip hover bridge** · a transparent 6px top border (with `background-clip: padding-box`) replaces the 6px gap so the box does not close while the pointer travels from the mark to it.
