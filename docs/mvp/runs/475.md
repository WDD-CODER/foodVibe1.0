## Final gate - Atlas
No migration and no Atlas write. Optional read-only count of purchase units whose `uom` is not a unit key (could not run locally: the local DB needs the `.env` login). In `mongosh` on the target DB:

```js
const units = new Set(db.taxonomyTerms.find({ kind: 'unit' }, { key: 1 }).toArray().map(t => t.key).concat(['kg','liter','gram','ml','unit','dish','tablespoon','teaspoon','cup','pinch','portion']))
db.products.aggregate([{ $match: { deletedAt: { $exists: false }, 'purchaseOptions.uom': { $exists: true } } }, { $unwind: '$purchaseOptions' }, { $match: { 'purchaseOptions.uom': { $exists: true, $ne: '' } } }, { $project: { uom: '$purchaseOptions.uom' } }]).toArray().filter(r => !units.has(r.uom)).length
```
