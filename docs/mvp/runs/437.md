## Decisions
- Added `src/app/core/utils/supplier-orders.util.ts` to the plan scope and exported `unitLabel` from it · the prep rows must show the same short unit text as the supplier orders; one-word change, no duplicate helper.
- The component keeps the chef's tab choice in a private `pickedMode_` signal over the `mode` input (no `linkedSignal`) · the repo has no `linkedSignal` use; switching tab also resets the checkboxes to all-checked.
- The runtime `<style>` holds a `@page pg-N` rule only for checked groups · matches "one rule per printed group"; the page element keeps its stable index N.
- The footer text is split on `{x}`, `{y}`, `{group}` of `prep_sheets_page_footer` and rebuilt as a CSS `content` list · the Hebrew wording stays in the dictionary. `{y}` is `counter(pages)` of the whole print job, as the plan specifies.
- Unknown stations (a recipe key no longer in the list) sort after the listed ones and before "כללי" · the plan only orders listed stations and "כללי".
- Excel: one worksheet per group, title row + event line + `prepSheetTableRows` (no checkbox column); sheet names lose `\ / * ? : [ ]`, are cut to 27 characters and made unique · Excel limits.
- `exportChecklist` keeps `recipes` in its signature (the facade is unchanged) and builds the recipe map from it; the plan comes from `EventPlanService.planFor(menu)`.
- The sheet's supplier row is view only (no export button), and `onExportChecklist` ignores `'by_supplier'` · plan P9.
- Removed the `ScalingService` inject from `MenuExportService` (no other use) and `getMenuChecklistPreviewPayload` from both services.
- Print "black" is the keyword `black` (not a hex literal) in the component scss · `cssLayer` bans hex literals.
