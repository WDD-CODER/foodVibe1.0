## Decisions
- D1 lock · `removeRow`/`updateRow` return early while `isSaving_()`; trash button and every row input / select get `[disabled]="isSaving_()"` · closes the save-in-flight hole.
- Spec (a) sets the unit through `updateRow` (what the unit select's change calls) instead of clicking the custom-select · the select is a CVA whose popup is not needed to prove the payload.
- Spec (b) awaits `whenStable()` before checking input `disabled` · ngModel applies `disabled` asynchronously.
- L1 · `.import-sr-only` removed, header label uses global `.visually-hidden`, `.import-table-wrap` is `position: relative` so the absolute label stays inside the scroll box.
- L2 · at ≤ `$break-mobile` (768px) table/tbody/tr/td become blocks, each row a grid card, `thead` visually hidden, labels from `data-label` (existing keys `name`, `unit`, `price`, `import_col_purchase_unit`, `category`), name cell not sticky, wrap `overflow: visible`. Desktop untouched.
- L3 · `padding-block-end` of `.product-import` is `calc(4.25rem + var(--space-4))` at all widths (FAB 3.5rem + 0.75rem offset + one step).
- Name pool used: none by the builder (no browser run).
