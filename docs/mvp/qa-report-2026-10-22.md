10. **Admin: delete business confirmation (Check 14)** — in the second confirmation step of the delete-business popup, the user must type the exact business name before the final delete button enables.
11. **Import: delete row and change unit (Check 35)** — `/inventory/import` preview. Deleting a row and changing another row's unit before saving: the deleted row is still saved. A deleted row must be removed from the payload sent to the save endpoint.
12. **Import page on mobile (Check 37)** — `/inventory/import` layout is broken and not centred; containers overflow horizontally; text/inputs cut off. No horizontal overflow, centred main container, inputs and table fit the screen.

15. **Staff deletion & DB cleanup (Check 50/118)** — `/settings?tab=team`. Deleting a staff member leaves the record in the `users` collection, so a new staff member with the same username fails (duplicate key). The username must be reusable.
16. **Menu Intelligence page background** — `app-menu-intelligence-page` has a background layer that masks the app background. Remove it.
17. **Close the event straight from the stage bar (Check 60)** — clicking «הסתיים» is blocked with a text message. Allow picking it; open a confirmation popup: «האם אתה בטוח שברצונך לסגור את האירוע ללא פוסט-פרודקשן?». Closing without post-production must not break any backend event flow or state.
18. **Notes container bottom padding (Check 65)** — event screen, widths 770–1030 px: notes are hidden behind the event details footer. Add bottom padding/spacing in that range.
19. **Coefficient manual override (Check 66)** — dish coefficient in the Menu Editor. Typing a value back to the exact default (without "Reset to default") still shows «שונה ידנית». Value equal to the default → no manual-change tag/state.
20. **Empty dish input rows** — Menu Editor dish/prep categories: several empty "Search dish or prep..." rows can be opened in one category. At most one empty row per category; no new empty row while one is open and unfilled. Empty rows are never saved or printed.
