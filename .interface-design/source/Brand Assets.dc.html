Food Composer identity

Five files in assets/, all vector. The shell serves the mark in the top bar and registers the favicon on every screen, so the app picks these up with no per-screen work. Explorations stay in Food Composer Logo.

Primary seal
assets/fc-seal.svg

Splash, sign-in, print, marketing. Never below 96px — below that it turns to texture.

App mark
assets/fc-mark.svg

Top bar, tabs, anywhere under 64px. FC is knocked out of the pot, so contrast survives the reduction.

Kitchen mark
assets/fc-mark-kitchen.svg

Cook View and any dark surface. Same geometry in kitchen teal — the shell swaps to it on theme="kitchen".

One ink
assets/fc-seal-ink.svg

Embroidery, foil, stamps, single-colour print. No cream field, no shading strokes — one paint value only.

Favicon
assets/fc-favicon.svg

Cream mark on a teal rounded tile, so it holds its own against a browser tab strip. Registered by the shell automatically.
