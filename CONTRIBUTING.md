# Contributing

FoodVibe is a private project and does not take outside contributions. Pull requests from outside are not accepted.

Questions and bug reports go to the author, [Dan Weibren](https://github.com/WDD-CODER). For a security problem, follow [SECURITY.md](SECURITY.md) instead.

## How work is done here

1. Every change starts as a written plan with acceptance criteria.
2. It goes through a branch and a pull request.
3. It passes CI (lint, build, unit and server tests, secret scan) and the architecture gates.
4. A person validates what a test cannot.

The code is published for viewing only. See [LICENSE](LICENSE).
