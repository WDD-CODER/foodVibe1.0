# Contributing

FoodVibe is a private project and does not take outside contributions. The source is published for viewing only (see
[LICENSE](LICENSE)). Questions and reports go to the author, [Dan Weibren](https://github.com/WDD-CODER).

## How work is done here

- Every change starts as a written plan with acceptance criteria.
- The change is built on its own branch and goes through a pull request.
- It passes CI (lint, build, unit and server tests, secret scan) and the architecture gates.
- A person validates what a test cannot.
