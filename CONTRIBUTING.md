# Contributing

FoodVibe is a private project built and maintained by one developer. It does not take outside contributions, and
pull requests from outside the project are not merged.

Questions, ideas and bug reports are welcome: contact the author through
[GitHub](https://github.com/WDD-CODER). For a security issue, follow [SECURITY.md](SECURITY.md) instead of opening
a public issue.

## How work is done here

- Every change starts as a written plan with a problem statement, the files it may touch and acceptance criteria.
- Each plan is built on its own branch and arrives as a pull request.
- Every pull request passes CI — lint, build, unit tests, server tests and a secret scan — and the architecture
  gates that check the project's written invariants.
- What a test cannot judge, such as how a screen looks and feels, is validated by a person before it ships.
